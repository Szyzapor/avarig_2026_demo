# Listening test v2 (webMUSHRA)

A MUSHRA-style follow-up to the AES 2026 (AVARIG) poster demo. It compares the
retrained **Proposed CRM** against the Zhu et al. 2022 and A2B (Gebru et al. 2025)
baselines on the same excerpts. Overall quality is rated first, then the SAQI
attributes.

## What changed since the AVARIG demo

- **Retrained proposed model:** `proposed_crm_v2` (internal name
  `popr9_mirror_rot_level`). It was trained on corrected data with name-based
  file pairing, per-file time and polarity alignment, and unified FOA channel
  conventions. The loss also penalises polarity and level errors.
- **No training-data leakage:** the four Argentum excerpts come only from
  recordings that the proposed model never saw during training. The
  conference demo used training recordings.
- **No loudness bias:** every stimulus is normalised to −23 LUFS
  (ITU-R BS.1770) with a common peak limit of −1 dBFS per trial.
- **Time and polarity matched to the reference:** done on the full 30 s demo
  clips. See `manifest.json` for the lag and polarity applied per clip.
- **Anchors:** a 3.5 kHz low-passed reference and a plain FOA render with
  virtual cardioids (no HRTF).

Note: the A2B checkpoint (`btpab`) was trained on the Zhu dataset, so A2B is
in-domain on the `zhu` trials.

## Trials

12 trials of 10 s each:

- 4 × Zhu (ByteDance) test set: `zhu_001`–`004`, the excerpts discussed at
  AVARIG,
- 4 × Meta A2B 2-MP test set: `a2b_2mp_001`–`004`,
- 4 × Argentum hold-out: `argentum_pg_001`, `002`, `003`, `008`, from four
  different recordings (concert, piano, choir, outdoor).

Stimuli per trial: hidden reference, `proposed_crm_v2`, `zhu2022`,
`a2b_btpab`, `anchor_lp3500`, `anchor_foa_cardioid`.

Pages:

1. intro,
2. volume,
3. overall quality (12 trials, random order),
4. four SAQI attribute blocks (tone colour, localisation/width,
   externalisation, artefacts), each with 12 trials in random order,
5. finish with a short questionnaire.

## Audio

The audio (193 MB, 72 WAV files at 24 bit) is not stored in git; it is
distributed as `avarig_2026_listening_test_v2.zip`. Layout after unzipping:

```
listening_test_v2/
├── webmushra_config.yaml
├── manifest.json
└── audio/<dataset>__<clip>/{reference,proposed_crm_v2,zhu2022,a2b_btpab,anchor_*}.wav
```

## Running with webMUSHRA

1. Get webMUSHRA (https://github.com/audiolabs/webMUSHRA) and serve it with
   PHP if you want results written to disk.
2. Copy this folder, with the unzipped `audio/`, to
   `webMUSHRA/configs/listening_test_v2/`. Stimulus paths in the config are
   relative to the webMUSHRA root (`configs/listening_test_v2/audio/...`).
3. Open `http://<host>/?config=listening_test_v2/webmushra_config.yaml`.

## Provenance

The test was generated by `code/build_listening_package.py` in the research
repository (working copy `Argentum_popr9`) from audio package v2 of the demo
(`avarig_2026_demo_audio`):

```
python code/build_listening_package.py --out listening_test_v2 \
    --demo-root <demo_audio_v2> --demo-index <demo_audio_v2>/configs/audio_index.json \
    --crm-label proposed_crm_v2 \
    --clips argentum_pg=argentum_pg_001,argentum_pg_002,argentum_pg_003,argentum_pg_008 \
    --no-realign --attributes
```
